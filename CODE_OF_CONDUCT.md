# Code of conduct

sealift welcomes anyone who wants to use it, report a problem, or improve it. This page says what that takes.

## Expected

- Assume good faith, and say what you mean.
- Discuss the code, the docs or the idea, not the person behind them.
- Accept a no from a maintainer. The project's scope is narrow on purpose, and a refusal is about fit.
- Read past the grammar of someone writing in a second language.

## Not accepted

Harassment, insults, discriminatory language, unwelcome sexual attention, publishing someone's private information, and sustained disruption. This applies in issues, pull requests, commits, and wherever someone represents the project.

## Reporting

Report a problem through GitHub's private reporting, as described in [SECURITY.md](SECURITY.md), and say that it concerns conduct. The report stays between you and the maintainer. The response ranges from a private word to a permanent ban from the repository.
